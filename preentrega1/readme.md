# Tienda Retro & Pop - Preentrega 1 TypeScript

Proyecto desarrollado como base para la tienda e-commerce de remeras temáticas (Fútbol, Música, Películas y Videojuegos).

Tecnologías utilizadas
- **Vite** (Entorno de desarrollo y empaquetador)
- **TypeScript** (Tipado estricto)
- **HTML5** & **CSS3** (Estructura y estilos personalizados)
- **Node.js / npm** (Gestor de dependencias)
